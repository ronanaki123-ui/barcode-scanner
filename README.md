#barcode-scanner
2026/11/4 作成開始
架空の製薬会社「ソシアル製薬」の製品群に対応した、ブラウザ完結型の高精度バーコード認識Webアプリケーション。


高精度スキャン: ネイティブAPIとZXingライブラリのハイブリッド処理に加え、多段階の画像二値化/コントラスト補正により掠れたバーコードを補正。

軽量・メンテナンス性: 外部ライブラリに依存しすぎないクリーンなCSS設計と非同期データローディング。

-------------------メモ-------------------
・ライブビュースキャン追加
・スキャンの統計追加
    ・読み取った商品データをNode.jsサーバーへ送信（fetch や WebSocket）
    ・PostgreSQLデータベースに「誰が・いつ・どの商品をスキャンしたか」を保存する → supabaseで
    ・保存が完了したら、接続しているすべての画面に向けてリアルタイムでブロードキャスト

    ・
        
・商品の概要詰める
    ・商品名
    ・値段
    ・在庫
    ・説明
    ・画像
・スキャン結果からその商品のページに飛べるように
